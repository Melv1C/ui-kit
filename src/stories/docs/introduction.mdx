# UI Kit Documentation

Bienvenue dans la documentation de **@melv1c/ui-kit** — une collection de composants UI réutilisables construite autour de **Tailwind CSS** et des composants **shadcn/ui**.

## À propos de cette librairie

- ✅ **Composants modernes** basés sur des patterns UI populaires
- ✅ **Entièrement typée** en TypeScript
- ✅ **Multilingue** avec i18n (EN, FR)
- ✅ **Accessible** (WCAG compliant)
- ✅ **Zero dépendances inutiles** — tu charges ce que tu utilises
- ✅ **Prêt pour la production** — utilisé en environnement professionnel

## Contenu

La documentation couvre :

- **Installation** – Comment installer et configurer la librairie
- **Get Started** – Premiers pas avec un exemple simple
- **Theming** – Personnaliser les couleurs et le design
- **Internationalisation** – Configurer plusieurs langues
- **Composants** – Tous les composants disponibles avec exemples interactifs

## Structure de ce projet

```
@melv1c/ui-kit/
├── src/
│   ├── components/      # Tous les composants
│   ├── hooks/           # Hooks réutilisables
│   ├── lib/             # Utilitaires
│   ├── locales/         # Traductions i18n
│   └── stories/         # Documentation MDX
├── .storybook/          # Configuration Storybook
└── tailwind.preset.js   # Configuration Tailwind par défaut
```
