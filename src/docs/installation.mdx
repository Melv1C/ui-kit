# Installation

## Prérequis

Avant de commencer, assure-toi d'avoir :

- **React 19+**
- **Node.js 22+**
- **Tailwind CSS 4+** configuré dans ton projet
- **TypeScript**

## Installation

```bash
npm install @melv1c/ui-kit
pnpm add @melv1c/ui-kit
yarn add @melv1c/ui-kit
bun add @melv1c/ui-kit
```

---

## Configuration

### 1. Tailwind Configuration

The library uses **Tailwind CSS** for styles. Add `@melv1c/ui-kit` to your Tailwind CSS file as a source:

```css
@import "tailwindcss";

@source '../node_modules/@melv1c/ui-kit';
```

### 2. Import Styles

Import the base styles and a theme in your main CSS file:

```css
@import "tailwindcss";
@import "tw-animate-css";

@source '../node_modules/@melv1c/ui-kit';

/* Import base theme structure */
@import "@melv1c/ui-kit/base.css";

/* Import a theme (choose one) */
@import "@melv1c/ui-kit/themes/default.css";
/* or */
@import "@melv1c/ui-kit/themes/exotic.css";
/* or */
@import "@melv1c/ui-kit/themes/vibrant.css";
```

### 3. Use Components

```tsx
import { Button, Card } from "@melv1c/ui-kit";

function App() {
  return (
    <Card>
      <Button>Click me</Button>
    </Card>
  );
}
```

---

## Available Themes

- **default.css** — Clean, neutral theme with zinc/slate colors
- **exotic.css** — Vibrant theme with coral and blue accents
- **vibrant.css** — Colorful theme with purple and yellow accents
