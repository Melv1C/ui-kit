# Theming

The UI Kit provides a flexible theming system built on CSS custom properties (CSS variables). You can easily customize the appearance of all components by modifying these variables.

## Quick Start

### 1. Import Base Styles

First, import the base CSS file that defines the theme structure:

```css
@import "@melv1c/ui-kit/base.css";
```

### 2. Choose a Theme

Then import one of the pre-built themes:

```css
@import "@melv1c/ui-kit/themes/default.css";
```

### Complete Example

```css
@import "tailwindcss";
@import "tw-animate-css";

@source "../node_modules/@melv1c/ui-kit";

@import "@melv1c/ui-kit/base.css";
@import "@melv1c/ui-kit/themes/default.css";
```

## Theme Variables

You can customize any theme by overriding these CSS custom properties in your own CSS file:

### Color Variables

#### Core Colors

```css
:root {
  /* Background & Foreground */
  --background: #ffffff;
  --foreground: #09090b;

  /* Card Component */
  --card: #ffffff;
  --card-foreground: #09090b;

  /* Popover Component */
  --popover: #ffffff;
  --popover-foreground: #09090b;

  /* Primary Actions */
  --primary: #18181b;
  --primary-foreground: #fafafa;

  /* Secondary Actions */
  --secondary: #f4f4f5;
  --secondary-foreground: #18181b;

  /* Muted Elements */
  --muted: #f4f4f5;
  --muted-foreground: #71717a;

  /* Accent Elements */
  --accent: #f4f4f5;
  --accent-foreground: #18181b;

  /* Destructive Actions */
  --destructive: #ef4444;
  --destructive-foreground: #fafafa;

  /* Borders & Inputs */
  --border: #e4e4e7;
  --input: #e4e4e7;
  --ring: #18181b;
}
```

#### Chart Colors

```css
:root {
  --chart-1: #e11d48;
  --chart-2: #f97316;
  --chart-3: #eab308;
  --chart-4: #22c55e;
  --chart-5: #3b82f6;
}
```

#### Sidebar Colors

```css
:root {
  --sidebar: #fbfbfc;
  --sidebar-foreground: #3f3f46;
  --sidebar-primary: #18181b;
  --sidebar-primary-foreground: #fafafa;
  --sidebar-accent: #f4f4f5;
  --sidebar-accent-foreground: #18181b;
  --sidebar-border: #e4e4e7;
  --sidebar-ring: #18181b;
}
```

### Border Radius

```css
:root {
  --radius: 0.5rem;
}
```

The base.css file automatically creates these calculated radius values:

- `--radius-sm`: `calc(var(--radius) - 4px)`
- `--radius-md`: `calc(var(--radius) - 2px)`
- `--radius-lg`: `var(--radius)`
- `--radius-xl`: `calc(var(--radius) + 4px)`

## Dark Mode

All themes include dark mode support. Dark mode is activated using the `.dark` class:

```css
.dark {
  --background: #09090b;
  --foreground: #fafafa;
  /* ... other dark mode colors */
}
```

To enable dark mode in your app, add the `dark` class to a parent element (typically `<html>` or `<body>`).

## Creating a Custom Theme

### Option 1: Override Variables

Create your own CSS file and override specific variables:

```css
@import "@melv1c/ui-kit/base.css";
@import "@melv1c/ui-kit/themes/default.css";

/* Override theme variables */
:root {
  --primary: #3b82f6;
  --primary-foreground: #ffffff;
  --accent: #8b5cf6;
  --radius: 1rem;
}

.dark {
  --primary: #60a5fa;
  --accent: #a78bfa;
}
```

### Option 2: Create a New Theme File

Create a complete theme file following the structure of existing themes:

```css
/* my-theme.css */
:root {
  --background: #f8fafc;
  --foreground: #0f172a;
  --primary: #0ea5e9;
  --primary-foreground: #ffffff;
  /* ... all other variables */
  --radius: 0.75rem;
}

.dark {
  --background: #0f172a;
  --foreground: #f8fafc;
  --primary: #38bdf8;
  /* ... all other dark mode variables */
}
```

Then import it instead of a pre-built theme:

```css
@import "@melv1c/ui-kit/base.css";
@import "./my-theme.css";
```

## Tips

- **Always import `base.css` first** — It sets up the necessary theme structure
- **Use HSL colors** for better control over lightness and saturation
- **Test both light and dark modes** when creating custom themes
- **Maintain contrast ratios** for accessibility (WCAG AA: 4.5:1 for normal text)
- **Keep foreground colors readable** against their respective backgrounds
