# Guide des composants

Tous les composants de `@melv1c/ui-kit` suivent les mêmes principes :

- ✅ **Composables** – Chaque composant peut être utilisé indépendamment
- ✅ **Accessibles** – WCAG 2.1 Level AA
- ✅ **Typés** – Full TypeScript support
- ✅ **Stylisables** – Avec `className` et Tailwind

---

## Catégories de composants

### 📦 Base Components

Les briques fondamentales :

- **Button** – Boutons avec variantes
- **Input** – Champs de saisie
- **Label** – Étiquettes de formulaire
- **Card** – Conteneurs

### 📋 Composables

Composants composables avec plusieurs sous-parties :

- **Dialog** – Fenêtres modales
- **Sheet** – Panneaux latéraux
- **Dropdown Menu** – Menus déroulants
- **Select** – Sélecteurs

### 🎨 Display

Composants d'affichage :

- **Badge** – Étiquettes
- **Avatar** – Images de profil
- **Alert** – Messages d'alerte
- **Toast** – Notifications

### 🧩 Complex

Composants avancés :

- **Calendar** – Calendriers
- **Chart** – Graphiques
- **CodeEditor** – Éditeur de code
- **RichTextEditor** – Éditeur WYSIWYG

---

## Pattern d'utilisation

### Composants simples

```tsx
import { Button } from "@melv1c/ui-kit";

<Button>Simple</Button>;
```

### Composants composables

```tsx
import { Card } from "@melv1c/ui-kit";

<Card>
  <Card.Header>
    <Card.Title>Titre</Card.Title>
  </Card.Header>
  <Card.Content>Contenu</Card.Content>
  <Card.Footer>Footer</Card.Footer>
</Card>;
```

### Composants avec state

```tsx
import { Dialog, Button } from "@melv1c/ui-kit";
import { useState } from "react";

export default function Example() {
  const [open, setOpen] = useState(false);

  return (
    <>
      <Button onClick={() => setOpen(true)}>Ouvrir</Button>
      <Dialog open={open} onOpenChange={setOpen}>
        {/* Contenu */}
      </Dialog>
    </>
  );
}
```

## Props communes

La plupart des composants acceptent ces props :

| Prop        | Type                   | Description                                    |
| ----------- | ---------------------- | ---------------------------------------------- |
| `className` | `string`               | Classes Tailwind additionnelles                |
| `disabled`  | `boolean`              | Désactiver le composant                        |
| `size`      | `"sm" \| "md" \| "lg"` | Taille du composant                            |
| `variant`   | `string`               | Variante visuelle                              |
| `asChild`   | `boolean`              | Wrapper avec un enfant personnalisé (Radix UI) |

---

## Variantes

Les variantes changent le style sans changer le comportement :

```tsx
<Button variant="primary">Primary</Button>
<Button variant="secondary">Secondary</Button>
<Button variant="outline">Outline</Button>
<Button variant="destructive">Delete</Button>
<Button variant="ghost">Ghost</Button>
```

---

## Tailles

La plupart des composants supportent plusieurs tailles :

```tsx
<Button size="sm">Small</Button>
<Button size="md">Medium</Button>
<Button size="lg">Large</Button>
```

---

## Accessibilité

Tous les composants respectent les standards d'accessibilité :

- ✅ Keyboard navigation (Tab, Enter, Escape)
- ✅ ARIA labels et roles
- ✅ Focus management
- ✅ Screen reader support

Exemple :

```tsx
<Dialog>
  <Dialog.Trigger asChild>
    <Button>Ouvrir</Button>
  </Dialog.Trigger>
  <Dialog.Content>
    <Dialog.Header>
      <Dialog.Title>Titre du dialog</Dialog.Title>
    </Dialog.Header>
    {/* Contenu accessible */}
  </Dialog.Content>
</Dialog>
```

---

## Composition avec `asChild`

Certains composants supportent `asChild` pour wrapper d'autres éléments :

```tsx
import { Button } from "@melv1c/ui-kit";
import { Link } from "react-router-dom";

<Button asChild>
  <Link to="/about">À propos</Link>
</Button>;
```

## Exports

Tous les composants et types sont exportés :

```tsx
// Composants
import { Button, Card, Dialog } from "@melv1c/ui-kit";

// Types
import type { ButtonProps, CardProps } from "@melv1c/ui-kit";
```

## Testing

Les composants peuvent être testés avec Vitest/Jest et React Testing Library :

```tsx
import { render, screen } from "@testing-library/react";
import { Button } from "@melv1c/ui-kit";

test("renders button", () => {
  render(<Button>Click me</Button>);
  expect(screen.getByRole("button", { name: /click me/i })).toBeInTheDocument();
});
```
