# UI Kit Documentation

Welcome to the documentation for **@melv1c/ui-kit** — a collection of reusable UI components built with **Tailwind CSS** and `shadcn/ui` primitives.

## Contents

This documentation covers:

- **Installation** - How to install and configure the library
- **Get Started** - First steps with a simple example
- **Theming** - Customize colors and design
- **Internationalization** - Configure multiple languages
- **Components** - All available components with interactive examples
