# Internationalization (i18n)

`@melv1c/ui-kit` ships with built-in translations for UI components.

Supported languages:

- 🇺🇸 English (EN)
- 🇫🇷 Français (FR)
- 🇳🇱 Nederlands (NL)
- 🇪🇸 Español (ES)
- 🇩🇪 Deutsch (DE)
- 🇮🇹 Italiano (IT)

---

## Installation

```bash
npm i i18next react-i18next
```

---

## Configuration

Wrap your app with `UIKitProvider` to enable UI kit translations. It supports two modes:

### Mode 1: Single Language (Locale Mode)

For apps that only need one language:

```jsx
import { UIKitProvider } from "@melv1c/ui-kit/providers";

function App() {
  return (
    <UIKitProvider i18nConfig={{ locale: "fr" }}>
      {/* Your app in French */}
    </UIKitProvider>
  );
}
```

#### Override translations

```jsx
<UIKitProvider
  i18nConfig={{
    locale: "fr",
    overrides: { next: "Avancer" },
  }}
>
  {/* ... */}
</UIKitProvider>
```

---

### Mode 2: Multiple Languages (i18n Instance Mode)

For apps with an existing i18n setup that need multiple languages:

#### 1. Initialize i18next in your app

```javascript
import i18n from "i18next";
import { initReactI18next } from "react-i18next";

i18n.use(initReactI18next).init({
  lng: "en",
  fallbackLng: "en",
  interpolation: {
    escapeValue: false,
  },
});
```

#### 2. Wrap your app with UIKitProvider

```jsx
import { UIKitProvider } from "@melv1c/ui-kit/providers";

function App() {
  return (
    <UIKitProvider i18nConfig={{ instance: i18n }}>
      {/* Your multilingual app */}
    </UIKitProvider>
  );
}
```

The `UIKitProvider` automatically adds all UI kit translations under the `ui` namespace for all supported languages.

#### Override or extend translations

```jsx
<UIKitProvider
  i18nConfig={{
    instance: i18n,
    overrides: {
      // Override existing language
      fr: { next: "Avancer" },
      // Add unsupported language
      ru: { next: "Следующий", previous: "Предыдущий" },
    },
  }}
>
  {/* ... */}
</UIKitProvider>
```
