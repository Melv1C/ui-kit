# Internationalization (i18n)

`@melv1c/ui-kit` ships with built-in translations for UI components.

Supported languages:

- 🇺🇸 English (EN)
- 🇫🇷 Français (FR)
- 🇳🇱 Nederlands (NL)
- 🇪🇸 Español (ES)
- 🇩🇪 Deutsch (DE)
- 🇮🇹 Italiano (IT)

---

## Installation

```bash
npm i i18next react-i18next
```

---

## Choose Your Setup

### Option 1: Single Language (LocaleProvider)

For apps that only need one language and don't have an existing i18n setup:

```jsx
import { LocaleProvider } from "@melv1c/ui-kit/providers";

function App() {
  return (
    <LocaleProvider language="fr">{/* Your app in French */}</LocaleProvider>
  );
}
```

#### Override translations

```jsx
<LocaleProvider language="fr" overrides={{ next: "Avancer" }}>
  {/* ... */}
</LocaleProvider>
```

---

### Option 2: Full i18n (TranslationProvider)

For apps with an existing i18n setup that need multiple languages:

#### 1. Initialize i18next in your app

```javascript
import i18n from "i18next";
import { initReactI18next } from "react-i18next";

i18n.use(initReactI18next).init({
  lng: "en",
  fallbackLng: "en",
  interpolation: {
    escapeValue: false,
  },
});
```

#### 2. Wrap your app with TranslationProvider

```jsx
import { TranslationProvider } from "@melv1c/ui-kit/providers";

function App() {
  return (
    <TranslationProvider i18n={i18n}>
      {/* Your multilingual app */}
    </TranslationProvider>
  );
}
```

The `TranslationProvider` automatically adds all UI kit translations under the `ui` namespace.

#### Override or extend translations

```jsx
<TranslationProvider
  i18n={i18n}
  overrides={{
    // Override existing language
    fr: { next: "Avancer" },
    // Add unsupported language
    ru: { next: "Следующий", previous: "Предыдущий" },
  }}
>
  {/* ... */}
</TranslationProvider>
```

---

### Option 3: Manual Setup

For full control, import locale files directly:

```javascript
import i18n from "i18next";
import { initReactI18next } from "react-i18next";
import { en as uiEn, fr as uiFr } from "@melv1c/ui-kit/locales";

i18n.use(initReactI18next).init({
  lng: "en",
  fallbackLng: "en",
  resources: {
    en: { ui: uiEn },
    fr: { ui: uiFr },
  },
  interpolation: {
    escapeValue: false,
  },
});
```
